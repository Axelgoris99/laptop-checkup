Keyboard test

Press every key: each one turns green when it registers. Free, nothing to install, nothing leaves your browser.

Buying a used laptop? The keyboard is one of 17 checks in the free Laptop Checkup: battery wear, dead pixels, ports, company locks and more, with a report you can copy at the end.

How to use it

  1. Click anywhere on the page so it receives your key presses.
  2. Press every key once. Keys that work turn green and the counter goes up.
  3. A key that stays blue after you let go is stuck.
  4. Right-click a key your keyboard doesn't have (numpad, extra keys) to grey it out. The counter then ignores it.
  5. Switch between AZERTY and QWERTY so the labels match the keys printed on your keyboard.

What to look for

  • Dead keys: nothing lights up, even after a firm press.
  • Keys that need a hard press, or only work when hit in the middle: usually dirt or a worn switch.
  • Double letters: type a sentence in the note field below the keyboard. A key that types twice is "chattering".
  • Backlight at every brightness level, and the Fn shortcuts for volume and brightness.
  • Shiny or worn keycaps show how much the laptop was used, whatever the seller says.

Questions

The Fn key never lights up. Is it broken?

No. Fn is handled by the laptop itself and never reaches the browser. Test it with its shortcuts instead: Fn plus the volume or brightness keys should work.

Print Screen or the Windows key do nothing

The operating system can catch some keys before the browser sees them. Print Screen often only registers when released; the test listens for that too. If a key still does nothing here, check it works in Windows itself.

Is what I type sent anywhere?

No. The test runs entirely in your browser and records nothing.
